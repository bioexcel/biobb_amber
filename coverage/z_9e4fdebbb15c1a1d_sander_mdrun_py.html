12 """ 

13 | biobb_amber SanderMDRun 

14 | Wrapper of the `AmberTools (AMBER MD Package) sander tool <https://ambermd.org/AmberTools.php>`_ module. 

15 | Runs energy minimization, molecular dynamics, and NMR refinements using sander tool from the AmberTools MD package. 

16 

17 Args: 

18 input_top_path (str): Input topology file (AMBER ParmTop). File type: input. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/data/sander/cln025.prmtop>`_. Accepted formats: top (edam:format_3881), parmtop (edam:format_3881), prmtop (edam:format_3881). 

19 input_crd_path (str): Input coordinates file (AMBER crd). File type: input. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/data/sander/cln025.inpcrd>`_. Accepted formats: crd (edam:format_3878), mdcrd (edam:format_3878), inpcrd (edam:format_3878), netcdf (edam:format_3650), nc (edam:format_3650), ncrst (edam:format_3886), rst (edam:format_3886), rst7 (edam:format_3886). 

20 input_mdin_path (str) (Optional): Input configuration file (MD run options) (AMBER mdin). File type: input. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/data/sander/npt.mdin>`_. Accepted formats: mdin (edam:format_2330), in (edam:format_2330), txt (edam:format_2330). 

21 input_cpin_path (str) (Optional): Input constant pH file (AMBER cpin). File type: input. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/data/sander/cln025.cpin>`_. Accepted formats: cpin (edam:format_2330), in (edam:format_2330), txt (edam:format_2330). 

22 input_ref_path (str) (Optional): Input reference coordinates for position restraints. File type: input. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/data/sander/sander.rst>`_. Accepted formats: rst (edam:format_3886), rst7 (edam:format_3886), netcdf (edam:format_3650), nc (edam:format_3650), ncrst (edam:format_3886), crd (edam:format_3878), inpcrd (edam:format_3878), mdcrd (edam:format_3878). 

23 output_log_path (str): Output log file. File type: output. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/reference/sander/sander.log>`_. Accepted formats: log (edam:format_2330), out (edam:format_2330), txt (edam:format_2330), o (edam:format_2330). 

24 output_traj_path (str): Output trajectory file. File type: output. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/reference/sander/sander.x>`_. Accepted formats: trj (edam:format_3878), crd (edam:format_3878), mdcrd (edam:format_3878), x (edam:format_3878), netcdf (edam:format_3650), nc (edam:format_3650). 

25 output_rst_path (str): Output restart file. File type: output. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/reference/sander/sander.rst>`_. Accepted formats: rst (edam:format_3886), rst7 (edam:format_3886), netcdf (edam:format_3650), nc (edam:format_3650), ncrst (edam:format_3886). 

26 output_cpout_path (str) (Optional): Output constant pH file (AMBER cpout). File type: output. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/reference/sander/sander.cpout>`_. Accepted formats: cpout (edam:format_2330). 

27 output_cprst_path (str) (Optional): Output constant pH restart file (AMBER rstout). File type: output. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/reference/sander/sander.cprst>`_. Accepted formats: cprst (edam:format_3886), rst (edam:format_3886), rst7 (edam:format_3886). 

28 output_mdinfo_path (str) (Optional): Output MD info. File type: output. `Sample file <https://github.com/bioexcel/biobb_amber/raw/master/biobb_amber/test/reference/sander/sander.mdinfo>`_. Accepted formats: mdinfo (edam:format_2330). 

29 properties (dict - Python dictionary object containing the tool parameters, not input/output files): 

30 * **mdin** (*dict*) - ({}) Sander MD run options specification. (Used if *input_mdin_path* is None) 

31 * **simulation_type** (*str*) - ("minimization") Default options for the mdin file. Each creates a different mdin file. Values: `minimization <https://biobb-amber.readthedocs.io/en/latest/_static/mdins/min.mdin>`_ (Runs an energy minimization), `min_vacuo <https://biobb-amber.readthedocs.io/en/latest/_static/mdins/min_vacuo.mdin>`_ (Runs an energy minimization in vacuo), `NVT <https://biobb-amber.readthedocs.io/en/latest/_static/mdins/nvt.mdin>`_ (Runs an NVT equilibration), `npt <https://biobb-amber.readthedocs.io/en/latest/_static/mdins/npt.mdin>`_ (Runs an NPT equilibration), `free <https://biobb-amber.readthedocs.io/en/latest/_static/mdins/free.mdin>`_ (Runs a MD simulation), `heat <https://biobb-amber.readthedocs.io/en/latest/_static/mdins/heat.mdin>`_ (Heats the MD system). 

32 * **binary_path** (*str*) - ("sander") sander binary path to be used. 

33 * **direct_mdin** (*bool*) - (False) Use input_mdin_path as it is, skip file parsing. 

34 * **mpi_bin** (*str*) - (None) Path to the MPI runner. Usually "mpirun" or "srun". 

35 * **mpi_np** (*int*) - (None) [0~1000|1] Number of MPI processes. Usually an integer bigger than 1. 

36 * **mpi_flags** (*str*) - (None) Path to the MPI hostlist file. 

37 * **remove_tmp** (*bool*) - (True) [WF property] Remove temporal files. 

38 * **restart** (*bool*) - (False) [WF property] Do not execute if output files exist. 

39 * **sandbox_path** (*str*) - ("./") [WF property] Parent path to the sandbox directory. 

40 * **container_path** (*str*) - (None) Container path definition. 

41 * **container_image** (*str*) - ('afandiadib/ambertools:serial') Container image definition. 

42 * **container_volume_path** (*str*) - ('/tmp') Container volume path definition. 

43 * **container_user_id** (*str*) - (None) Container user_id definition. 

44 * **container_shell_path** (*str*) - ('/bin/bash') Path to default shell inside the container. 

45

75 def __init__(self, input_top_path: str, input_crd_path: str, output_log_path: str, output_traj_path: str, output_rst_path: str, 

76 input_ref_path: Optional[str] = None, input_mdin_path: Optional[str] = None, input_cpin_path: Optional[str] = None, output_cpout_path: Optional[str] = None, output_cprst_path: Optional[str] = None, output_mdinfo_path: Optional[str] = None, 

77 properties: Optional[dict] = None, **kwargs) -> None: 

78 super().__init__(**locals())

80 def create_mdin(self, path: Optional[str] = None) -> str: 

81 """Creates an AMBER MD configuration file (mdin) using the properties file settings""" 

82 return write_mdin(str(path), self.io_dict['in']['input_mdin_path'], self.mdin, self.simulation_type, self.direct_mdin) 

83 

84 def run(self): 

85 """Launches the execution of the BuildLinearStructure module.""" 

86 

87 # Sander configuration (instructions) file, in the sandbox 

88 self.output_mdin_path = self.staged_path(self.create_mdin(path=self.create_tmp_file("_sander.mdin"))) 

89 

90 # Command line 

91 # sander -O -i mdin/min.mdin -p $1.cpH.prmtop -c ph$i/$1.inpcrd -r ph$i/$1.min.rst7 -o ph$i/$1.min.o 

92 self.cmd = [self.binary_path, 

93 '-O', 

94 '-i', self.output_mdin_path, 

95 '-p', self.stage_io_dict['in']['input_top_path'], 

96 '-c', self.stage_io_dict['in']['input_crd_path'], 

97 '-r', self.stage_io_dict['out']['output_rst_path'], 

98 '-o', self.stage_io_dict['out']['output_log_path'], 

99 '-x', self.stage_io_dict['out']['output_traj_path'] 

100 ] 

101 

102 if self.io_dict['in']['input_ref_path']: 

103 self.cmd.append('-ref') 

104 self.cmd.append(self.stage_io_dict['in']['input_ref_path']) 

105 

106 if self.io_dict['in']['input_cpin_path']: 

107 self.cmd.append('-cpin') 

108 self.cmd.append(self.stage_io_dict['in']['input_cpin_path']) 

109 

110 if self.io_dict['out']['output_mdinfo_path']: 

111 self.cmd.append('-inf') 

112 self.cmd.append(self.stage_io_dict['out']['output_mdinfo_path']) 

113 

114 if self.io_dict['out']['output_cpout_path']: 

115 self.cmd.append('-cpout') 

116 self.cmd.append(self.stage_io_dict['out']['output_cpout_path']) 

117 

118 if self.io_dict['out']['output_cprst_path']: 

119 self.cmd.append('-cprestrt') 

120 self.cmd.append(self.stage_io_dict['out']['output_cprst_path']) 

121 

122 # general mpi properties 

123 if self.mpi_bin: 

124 mpi_cmd = [self.mpi_bin] 

125 if self.mpi_np: 

126 mpi_cmd.append('-n') 

127 mpi_cmd.append(str(self.mpi_np)) 

128 if self.mpi_flags: 

129 mpi_cmd.append(self.mpi_flags) 

130 self.cmd = mpi_cmd + self.cmd 

131 

132 # Run Biobb block 

133 self.run_biobb() 

134 

135 def write_parameter_files(self, directory: str) -> list[str]: 

136 """Write the mdin file to **directory** without executing sander, used by the 

137 provenance of the executions skipped by the restart property.""" 

138 return [self.create_mdin(path=str(Path(directory).joinpath("sander.mdin")))]
